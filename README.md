# Facility Reservation System

## Project Description
This is a web-based Facility Reservation System developed using Laravel and MySQL. The system allows users to reserve facilities online while administrator can manage facilities, reservations, and users.

## Features
- User Registration and Login
- Facility Management
- Facility Reservation
- Reservation Approval
- Reservation History
- Admin Dashboard
